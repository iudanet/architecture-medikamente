## Диаграммы потоков данных

По одной диаграмме на процесс. В каждом `.drawio` две страницы: As-Is и To-Be.
- **As-Is:** конфиденциальные данные выделены красным с тегом в скобках, ручные шаги помечены, риски обозначены как `R1…`.
- **To-Be:** на потоках и хранилищах отмечены меры защиты.

В To-Be номер хранилища сохраняется за системой, которая заменяет исходное хранилище. Excel-учёт платежей (D6) и локальные копии аналитика (D10) упразднены.

## Конфиденциальные данные, не учтённые во внутренних системах

| Данные | Где находятся | Почему не учтены |
|---|---|---|
| Расширенная анкета пациента: адрес, место работы или учёбы, хронические заболевания | Excel `Patients`, сканы | Сведения о здоровье хранятся в общем файле вместе с контактами, без категории и отдельного согласия |
| Журналы записи `Journal-Doctor-FIO` | Excel на общем диске | Связка «пациент — специалист» раскрывает сведения о здоровье (визит к онкологу и т. п.) |
| Медицинские документы: заключения, сканы, фото | Папки `Pacient-FIO-BD` | ФИО и дата рождения в имени папки; файлы без описи, владельца и срока хранения |
| Результаты анализов | Excel `RegistryByDate`, почта, бумага | Реестр за день содержит данные всех пациентов; результаты приходят по почте |
| Паспорт, полис ОМС/ДМС, СНИЛС пациента | Сканы договоров | Хранятся как изображения, по ним нет поиска, контроля и удаления |
| Сочетание «ФИО + услуга + сумма» | Excel платежей кассы | Дублирует 1С; наименование услуги раскрывает медсведения |
| Кадровые данные: паспорт, СНИЛС, ИНН, реквизиты, медкнижки | Сканы на общем диске, база 1С | Файл базы 1С в файловом режиме доступен по сети |
| Вложения с ПДн в почте | Exchange, локальные `.pst` | Почта не входит в учёт хранилищ ПДн |
| Выгрузки для аналитики | Рабочий ПК аналитика (Jupyter) | Полные копии ПДн и медданных вне учёта |
| Неформальные каналы: личные мессенджеры, флешки, локальные копии журналов | Личные устройства, рабочие ПК | Не видны ИТ и не контролируются |
